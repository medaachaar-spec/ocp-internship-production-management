# Data Dictionary

## Nature des données

Les données opérationnelles de cette base sont entièrement synthétiques. Elles sont inspirées de références publiques relatives à Phosboucraa et de benchmarks issus de mines à ciel ouvert comparables. Elles ne constituent ni des données internes, ni des chiffres opérationnels officiels d'OCP.

The prototype uses neutral internal codes and fictional records. Real OCP field names, locations, fleet identifiers, employee identities, production volumes, quality thresholds, and shift rules must be confirmed with the supervisor before any real-data mapping.

| Column | Type | Required | Purpose | Source | Related Dashboard |

| TruckID | INT IDENTITY | Yes | Technical primary key. | Generated by SQL Server. | Trips, truck stops, truck performance |

| RegistrationNumber | NVARCHAR(30) | No | Fictional prototype registration label. | Prototype assumption. | Truck performance |
| Model | NVARCHAR(80) | No | Generic fictional truck class, not a real OCP model. | Prototype assumption. | Truck performance |
| RatedPayloadTonnes | DECIMAL(10,2) | No | Fictional rated payload: 55 t, 70 t, or 90 t. | Benchmark-informed prototype assumption. | Payload realism checks |

| IsActive | BIT | Yes | Indicates whether the reference record is active. | Prototype reference list. | Filtering |
| CreatedAt | DATETIME2(0) | Yes | Record creation timestamp. | SQL Server default. | Audit support |

## Trip

Transaction table for fictional internal mining haulage movements. Trips represent internal movements such as extraction area to collection point, crusher/treatment feed, temporary stockpile, or internal dispatch feed. They do not represent road transport over the Boucraa-Laayoune distance.

| Column | Type | Required | Purpose | Source | Related Dashboard |
|---|---:|---|---|---|---|
| TripID | BIGINT IDENTITY | Yes | Technical primary key. | Generated by SQL Server. | Trips, performance |
| TripDate | DATE | Yes | Operational date of the sampled trip. | Prototype generator. | Trips by day |
| ShiftID | INT | Yes | Simulated shift. | Foreign key to WorkShift. | Trips, driver performance |
| TruckID | INT | Yes | Fictional truck used for the trip. | Foreign key to Truck. | Trips by truck, truck performance |
| DriverID | INT | Yes | Fictional driver assigned to the trip. | Foreign key to Driver. | Trips by driver, driver performance |
| LoadingPointID | INT | Yes | Neutral loading point. | Foreign key to LoadingPoint. | Trips, quality mapping |
| DestinationID | INT | Yes | Generic internal destination. | Foreign key to Destination. | Trips |
| StartTime | DATETIME2(0) | Yes | Trip start timestamp. | Deterministic prototype generator. | Trip duration |
| EndTime | DATETIME2(0) | No | Trip end timestamp. Null for incomplete or in-progress rows. | Deterministic prototype generator. | Trip duration |
| Tonnage | DECIMAL(10,2) | No | Positive payload for completed trips, compatible with fictional truck capacity. | Benchmark-informed prototype generator. | Tonnage reporting |
| Status | NVARCHAR(20) | Yes | Completed, InProgress, or Incomplete in generated data. | Prototype assumption. | Completed and incomplete trips |
| Comments | NVARCHAR(500) | No | Notes for analytical long trips or controlled underload cases. | Prototype generator. | Validation support |
| CreatedAt | DATETIME2(0) | Yes | Record creation timestamp. | SQL Server default. | Audit support |

The 800 generated trips over 30 days are a partial analytical sample for dashboard demonstration, not the complete monthly production of Phosboucraa.

## TruckStop

Transaction table for fictional downtime events linked to trucks and optionally to trips, drivers, and shifts.

| Column | Type | Required | Purpose | Source | Related Dashboard |
|---|---:|---|---|---|---|
| TruckStopID | BIGINT IDENTITY | Yes | Technical primary key. | Generated by SQL Server. | Truck stops |
| TruckID | INT | Yes | Truck affected by the stop. | Foreign key to Truck. | Downtime by truck |
| DriverID | INT | No | Driver linked to the stop when known. | Optional foreign key to Driver. | Truck stops |
| ShiftID | INT | No | Shift linked to the stop when known. | Optional foreign key to WorkShift. | Stops by shift if needed |
| TripID | BIGINT | No | Trip linked to the stop when known. | Optional foreign key to Trip. | Trip context |
| StopReasonID | INT | Yes | Reason for the stop. | Foreign key to StopReason. | Downtime by reason |
| StartTime | DATETIME2(0) | Yes | Stop start timestamp. | Deterministic prototype generator. | Stops by day |
| EndTime | DATETIME2(0) | No | Stop end timestamp. Generated stops have valid end times. | Deterministic prototype generator. | Downtime |
| DurationMinutes | Computed INT | No | Computed stop duration in minutes. | Calculated from StartTime and EndTime. | Total downtime, average stop duration |
| ValidationStatus | NVARCHAR(20) | Yes | Generated stops are validated in this prototype dataset. | Prototype assumption. | Data quality checks |
| Comments | NVARCHAR(500) | No | Notes explaining synthetic mechanical, preventive, or waiting events. | Prototype generator. | Validation support |
| CreatedAt | DATETIME2(0) | Yes | Record creation timestamp. | SQL Server default. | Audit support |

## QualityResult

Transaction table for single-metric P2O5 quality analyses in this MVP.

| Column | Type | Required | Purpose | Source | Related Dashboard |
|---|---:|---|---|---|---|
| QualityResultID | BIGINT IDENTITY | Yes | Technical primary key. | Generated by SQL Server. | Quality |
| AnalysisDate | DATETIME2(0) | Yes | Analysis timestamp. | Deterministic prototype generator. | Quality by date |
| TripID | BIGINT | No | Trip linked to the quality result when known. | Optional foreign key to Trip. | Trip quality context |
| LoadingPointID | INT | No | Loading point linked to the sample when known. | Optional foreign key to LoadingPoint. | Quality by loading point |
| QualityValue | DECIMAL(10,3) | Yes | P2O5 value in percent for the MVP. | Benchmark-informed prototype generator. | Quality summary |
| QualityUnit | NVARCHAR(20) | Yes | Uses `P2O5Percent` in this MVP. | Prototype assumption. | Quality summary |
| TargetValue | DECIMAL(10,3) | No | Prototype comparison value only; not an official threshold. | Prototype assumption. | Quality review |
| Status | NVARCHAR(20) | Yes | Prototype review band: InTarget, BelowTarget, AboveTarget, or Review. | Prototype assumption. | Quality status |
| Comments | NVARCHAR(500) | No | Notes stating thresholds are not official. | Prototype generator. | Validation support |
| CreatedAt | DATETIME2(0) | Yes | Record creation timestamp. | SQL Server default. | Audit support |

BPL, moisture, SiO2/insolubles, and optional CO2 are documented as future extensions rather than implemented in this MVP schema.
